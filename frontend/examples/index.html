Examples

Same engine, different stories. Here is how organizers use rules for teams, events, and shifts — each one has a matching preset you can load in the app.

sports_soccer

Sports teams

Place players into teams while balancing skill, honoring teammate requests, matching practice nights, capping keepers, and requiring a coach.

  • Balance skill across teams
  • Cluster teammate requests and availability
  • Hard limits on roles (keepers / coaches)
Tutorial
science

Science Olympiad

Students pick ranked event preferences. Conflict groups keep overlapping time blocks from double-booking the same person.

  • Cluster 1st–6th choice preferences to event names
  • Two slots per student by default
  • Time-block conflicts handled in Setup
Tutorial
volunteer_activism

Volunteer shifts

Match people to shifts by strengths and availability — soft cluster rules guide fair coverage without rigid one-off spreadsheet formulas.

  • Cluster strengths > shift needs
  • Cluster availability > time blocks
  • Easy to extend with Limit / Balance rules
