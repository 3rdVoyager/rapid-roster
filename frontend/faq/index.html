FAQ

Short answers about browser saves, rules, and getting data in.

Do I need an account?

No. RapidRoster runs in this browser for now. Cloud accounts and sync are coming later — until then, projects save on this device only.

Where is my data stored?

Projects live in this browser’s local storage on this device. Clearing site data or switching browsers removes them. See the Privacy page for details.

What are hard vs soft rules?

Hard rules must never break — illegal placements are rejected. Soft rules guide the score; partial success still counts. Priority (1–10) says what to protect first when tradeoffs appear. More in the Docs explanations.

How do I import people and slots?

Use CSV import on the Entries and Slots panels, or load a sample preset from a new project. Column types (ID, Number, Text, Time, Ignore) tell RapidRoster how to read each field. Semicolons can hold multiple values in one cell.

Why only five options after Generate?

Generate runs many searches, keeps the best unique layouts, and only stops early once it has a full set of five and scores stop improving. You see up to five ranked options so you can compare without drowning in near-duplicates.

Is RapidRoster free / open source?

Yes. The project is open source under the MIT License. You can use it, fork it, and adapt it for your own events.
