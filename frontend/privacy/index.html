Privacy

Plain-language notes on what RapidRoster stores. This is an early product page, not a law-firm policy — ask if you need something more formal.

In this browser

Projects stay in your browser (local storage) on this device. We do not receive those project contents. Clearing site data or using another browser removes local projects.

Accounts later

Cloud accounts and sync are not available yet. When they return, sign-in will use email and store only what you choose to sync. Generation still runs in your browser for typical roster sizes.

What we use data for

  • Hosting the static app and optional API routes on Cloudflare Pages
  • Operating and debugging the service (for example, server logs if you hit an API)
  • Later: saving cloud projects if you opt into accounts when that ships

We do not sell your project contents. Project CSVs may include names and other details you import — treat shared devices carefully.

Your choices

  • Keep using RapidRoster locally in this browser
  • Delete projects you no longer need from the Projects list
  • Export a project JSON if you want a backup outside the browser
  • Contact us with privacy or data questions
